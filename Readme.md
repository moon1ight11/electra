# Electra

Сервис для управления заказами небольшого бизнеса электриков. Три роли: клиенты (лендинг), исполнители (отчёты), владелец (статистика и управление).

## Возможности

- **Лендинг** — публичная страница с примерами работ, контактами и формой заявки
- **Аутентификация** — JWT-токены в HttpOnly cookies, вход по телефону и паролю
- **Управление заявками** — приём заявок с сайта, создание заказов из заявок, отмена
- **Управление заказами** — создание прямых заказов, назначение исполнителей, редактирование, завершение
- **Отчёты исполнителей** — заполнение времени, заработка, материалов и заметок по каждому заказу
- **Статистика** — сводка по компании, статистика по каждому исполнителю, топ-лист
- **Ролевая модель** — Worker (исполнитель), Owner (владелец-исполнитель)
- **Специализации** — возможность указать специализацию исполнителя (электрик, отделочник и т.д.)

## Технологический стек

- **Основной язык** — Go 1.25
- **HTTP-фреймворк** — Gin
- **База данных** — PostgreSQL 17
- **Миграции базы данных** — Goose
- **Аутентификация** — JWT (golang-jwt v5)
- **Безопасность** — bcrypt для хэширования паролей
- **Конфигурация** — Viper
- **Логирование** — Slog + lumberjack (ротация логов)
- **Документация** — OpenAPI 3.0
- **Фронтенд** — React (Create React App)
- **Контейнеризация** — Docker, Docker Compose
- **Архитектура** — Clean Architecture

## Архитектура

Проект построен на принципах **Clean Architecture** с чётким разделением на слои:

- **Handler** — HTTP-обработчики (Gin)
- **Service** — бизнес-логика приложения
- **Repository** — слой доступа к данным (PostgreSQL)
- **Domain** — модели, не зависящие от внешних фреймворков

## Быстрый старт

### Предварительные требования

- Go 1.25+
- Node.js 18+
- Docker и Docker Compose

### Локальный запуск

**1. Клонировать репозиторий**

```Shell
git clone https://github.com/moon1ight11/electra
cd electra
```

**2. Настроить конфигурацию**

```Shell
cp config.example.yml config.yml
# Указать параметры подключения к БД, JWT-секрет и т.д.
```

**3. Запустить инфраструктуру**

```Shell
docker-compose up -d
```

**4. Запустить бэкенд**

```Shell
go run cmd/main.go
```

**5. Запустить фронтенд**

```Shell
cd electra_front
npm install
npm start
```

Сервер будет доступен на [http://localhost:8080](http://localhost:8080/)
Фронтенд будет доступен на [http://localhost:3000](http://localhost:3000/)

## Особенности реализации

### Ролевая модель

* **Worker** — видит только свои заказы, заполняет отчёты
* **Owner** — видит все заказы, заявки, статистику; может быть назначен исполнителем

Владелец физически работает наравне с исполнителями. Один заказ может выполняться несколькими исполнителями.

### Транзакции и целостность данных

* Создание заказа с назначением исполнителей — в одной транзакции
* Конвертация заявки в заказ с пометкой заявки — атомарно
* Завершение заказа проверяет, что исполнитель назначен
* Удаление исполнителя с заказа не удаляет его отчёты из статистики

### Логирование

* Структурированное логирование с уровнями `DEBUG`, `INFO`, `WARN`, `ERROR`
* Запись логов в файл с автоматической ротацией (`lumberjack`)
* Логирование всех ключевых операций: создание заказа, заполнение отчёта, завершение

### Безопасность

* Пароли хэшируются с помощью **bcrypt**
* **JWT-токены** хранятся в HttpOnly cookie (защита от XSS)
* Валидация телефона — только цифры, минимум одна цифра
* Настроены политики **CORS** для безопасного взаимодействия с фронтендом
* **Role-based middleware** для защиты owner-эндпоинтов

